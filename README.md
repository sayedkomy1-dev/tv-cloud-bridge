# جسر التصفح السحابي المتكامل للتلفزيون الذكي (TV Cloud Bridge v1.2)

سيرفر سحابي خفيف يحل قيود أندرويد 4.4.2 (الشهادات، TLS 1.3، JavaScript الحديث، والرامات المحدودة) ويوفر 5 أدوات متكاملة:

1. **جسر التصفح السحابي (`/`)**: فتح المواقع الحديثة (مثل منصة **بالقرآن نحيا**) بمتصفح Chromium حديث وبثها للتلفزيون بواجهة ES5 خفيفة.
2. **وسيط تحميل الموارد + الكاش الذكي (`/fetch?url=...`)**: لتنزيل الخطوط (`.ttf`/`.woff2`)، الصوتيات (`.mp3`)، والبيانات (`.json`) لتطبيقات التلفزيون مع كاش ذكي في الذاكرة لتسريع التحميل.
3. **مستخرج الصوت المباشر (`/audio`)**: استخراج روابط الصوت/MP3 من الصفحة وتشغيلها مباشرة عبر مشغل التلفزيون.
4. **وضع القراءة النقي (`/read`)**: استخلاص النصوص والمقالات وعرضها بخط عربي كبير وواضح مريح للعين من بعيد.
5. **ريموت الموبايل (`/remote`)**: صفحة تفتحها من هاتفك لإرسال الروابط والنصوص والتحكم في التلفزيون بسهولة.

## خطوات الرفع على GitHub ثم Render.com (مجاني):
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `tv-cloud-bridge`).
2. ارفع جميع ملفات هذا المجلد إلى المستودع.
3. ادخل على [Render.com](https://render.com/) -> **New +** -> **Blueprint** (أو **Web Service**)، واربط المستودع على الخطة المجانية (**Free**).
